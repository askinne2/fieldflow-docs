The **Recent syncs** list on the Sync tab shows your project's latest syncs, both manual and automatic.

## Reading the list

Each entry shows:

| Item | Description |
|---|---|
| **Time** | When the sync started and finished |
| **Status** | Completed, Failed, Processing, or Queued |
| **Type** | Manual (someone clicked Sync now) or Scheduled (automatic) |
| **Records** | Records processed, and how many were created, updated, and deleted |
| **Warnings** | For example, **Row limit reached** |
| **Error** | The error message, if the sync failed |

The list shows the 10 most recent syncs.

## Status meanings

| Status | What it means |
|---|---|
| **Completed** | The sync finished |
| **Processing** | The sync is running now |
| **Queued** | The sync is waiting to start |
| **Failed** | The sync hit an error |

## Row limit reached

If your sheet has more rows than your plan allows, you'll see **Row limit reached — only the first [number] rows were synced**. Upgrade your plan or remove rows from the sheet. See [Plans & Pricing](/billing/plans/).

## Troubleshooting failed syncs

Check that:
- Google Sheets is still connected for your organization (see the **Overview** tab). If it isn't, click **Connect Google Sheets**
- The connected Google account can still open the spreadsheet
- The Sheet ID and worksheet name under **Data source** on the Overview tab are correct. The worksheet name must match the tab name exactly
- The spreadsheet hasn't been deleted or moved

If a sync keeps failing, contact [support@fieldflow.io](mailto:support@fieldflow.io) and include the error message from the sync list.
