title: Create a Project
description: Set up a FieldFlow project by connecting it to a Google Sheet.
---

A project in FieldFlow is one directory. Each project connects to one Google Sheet and has its own fields, layout, filters, and embed code.

:::note
You need a Starter or Professional plan (or a free trial) to create projects. See [Plans & Pricing](/billing/plans/).
:::

## Create a new project

1. Click **New Project** in the left sidebar
2. Fill in the form:

| Field | Required | Description |
|---|---|---|
| **Organization** | Yes | Which organization owns this project |
| **Project name** | Yes | A name for your directory (for example, "Resource Directory") |
| **Description** | No | A short note for your team |
| **Google Sheet ID** | Yes | The ID from your spreadsheet URL ([how to find it](/getting-started/connect-google-sheets/#finding-your-google-sheet-id)) |
| **Worksheet name** | No | Defaults to "Sheet1". Change it if your data is on a different tab |

3. Click **Create project**

You'll land on the project's **Overview** tab.

## Project tabs

Each project has these tabs:

| Tab | What it's for |
|---|---|
| **Overview** | Name, description, Google connection, and on/off switches for detail pages, map view, and Quiz Flow |
| **Configure** | Sub-tabs for **Fields**, **Display**, **Detail Page**, **Filters & Sorting**, and **Quiz** |
| **Sync** | Run a sync, set up automatic sync, and see recent syncs |
| **Publish** | Share links, embed code, and API keys |
| **Advanced** | Delete the project |

## What happens next

The Overview tab shows a quick start guide. In order:

1. **Connect Google Sheets** if you haven't yet
2. **Map your fields** in **Configure** > **Fields**
3. **Design the card layout** in **Configure** > **Display**
4. **Set up filters** in **Configure** > **Filters & Sorting**
5. **Run a sync** from the **Sync** tab
6. **Publish** from the **Publish** tab

## How your spreadsheet should be structured

FieldFlow works best when your Google Sheet is a simple table:

- **Row 1** has the column headers (for example, Name, Phone, Address, Category)
- **Each row below** is one record in your directory
- Avoid merged cells, nested tables, or more than one header row

## Delete a project

1. Open the project and go to the **Advanced** tab
2. Click **Delete project** and confirm

This removes the project's synced data and layout settings. It can't be undone. Your Google Sheet isn't affected.
