The embed code is a small HTML snippet you paste into your website. It shows your FieldFlow directory or quiz right on your page.

## Get your embed code

1. Go to your project's **Publish** tab
2. In **Embed on your site**:
   - Choose an **Embed type**: **Directory only**, **Quiz only**, or **Quiz + directory**
   - Choose a theme: **System (follow device)**, **Light**, or **Dark**
   - Optionally, pre-select categories (see [Start with filters](#start-with-filters))
3. Click **Copy code**
4. Replace `YOUR_API_KEY` in the snippet with a key from **API keys for embed** on the same tab. See [API Keys](/publishing/api-keys/)

:::tip
When you create a new API key, the confirmation panel has a **Copy full embed code** button that copies the snippet with the key already filled in.
:::

## The embed snippet

A directory embed looks like this:

```html
<div id="fieldflow-directory"></div>
<script>
  window.FieldFlow = window.FieldFlow || { q: [] };
  window.FieldFlow.q.push({
    projectId: "your-project-id",
    apiKey: "YOUR_API_KEY",
    container: "#fieldflow-directory",
    apiBaseUrl: "https://getfieldflow.io",
    options: { showSearch: true, showFilters: true, itemsPerPage: 20 }
  });
</script>
<script src="https://getfieldflow.io/embed.js" async></script>
```

Always copy the snippet from the Publish tab rather than typing it. It fills in your project ID and the options you picked.

## Embed types

### Directory only
The full directory with search and filters. This is the default.

### Quiz only
Shows just the quiz. Set **Redirect path after quiz** (for example, `/resources`). When a visitor finishes, they're sent to that path on your site, with their answers added to the URL as filter parameters.

### Quiz + directory
Shows the quiz first, then the results in the same embed, with a **Start over** option.

See [Quiz Flow](/quiz-flow/overview/) to set up a quiz.

## Theme

- **System (follow device)**: matches the visitor's light or dark mode setting
- **Light**: always light
- **Dark**: always dark

Use Light or Dark to match your page's background. Light and Dark add a `theme` line to the snippet.

## Start with filters

For **Directory only** and **Quiz + directory**, you can have the directory load with some categories already selected:

1. Under **Start with filters (optional)**, check **Pre-select categories in the embed**
2. Pick a **Category column**
3. Check the terms to pre-select

The snippet updates automatically. Click **Clear pre-filter** to remove it.

If no categories are listed, turn on **Enable filtering** for a taxonomy in **Configure** > **Filters & Sorting**, then sync.

## Detail pages in embeds

If [detail pages](/display/detail-pages/) are on, clicking a record opens its details inside the embed, with a **Back to directory** button. To open your own pages instead, see [Detail URL template](/embedding/advanced-options/#detail-url-template).
