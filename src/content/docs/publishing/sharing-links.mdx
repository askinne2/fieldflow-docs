---
title: Sharing Links
description: Share your directory, quiz, and detail page links directly.
---

Every FieldFlow project has a hosted directory page you can link to. No embed code needed.

## Directory link

Your hosted directory lives at:

```
https://getfieldflow.io/d/[your-project-id]
```

Find this link in the **Share** card on the **Publish** tab. You'll also see it under **View your directory** on the Overview and Sync tabs. Click **Copy** to copy it, or open it in a new tab.

It's a full directory with search, filters, and pages of results. Anyone with the link can view it.

## Quiz link

If you've set up a quiz, a quiz link appears too:

```
https://getfieldflow.io/d/[your-project-id]/quiz
```

Visitors start with the quiz, then see filtered results.

To get this link, activate a quiz in **Configure** > **Quiz** and check **Show Quiz Flow link in Publish tab** on the **Overview** tab.

## Detail page links

If detail pages are on, each record has its own link:

```
https://getfieldflow.io/p/[your-project-id]/[record-id]
```

Visitors reach these by clicking a record in the directory. You can copy a record's link from your browser, or with the **Share** button on the detail page.

## Links or embeds?

| Use case | Best option |
|---|---|
| Quick share by email, text, or social media | Sharing link |
| Show the directory on your website so visitors never leave | [Embed code](/publishing/embed-code/) |
| Link from a newsletter | Sharing link |
| Add to your website's navigation menu | Either works |

Sharing links open the directory on `getfieldflow.io`. Embeds show it on your own website.
