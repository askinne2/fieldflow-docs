---
title: API Keys
description: Create and manage API keys for your directory embeds.
---

Embeds need an API key to load your directory data. You manage keys on any project's **Publish** tab, in the **API keys for embed** section.

API keys belong to your **organization**. A key works for every project in the organization, and the list is the same on every project's Publish tab.

## Create an API key

1. Go to a project's **Publish** tab
2. In **API keys for embed**, click **Create API key**
3. Fill in:
   - **Key name (optional)**: a label for your reference, like "WordPress site"
   - **Access scope**: **Read-only** (recommended for embeds) or **Full**
   - **Allowed origins (optional)**: the websites that may use this key
4. Click **Create key**

The new key is shown right away. Click **Copy key**, or **Copy full embed code** to copy the snippet with the key filled in. Click **Done** when finished.

You can see the key again later. Click **Reveal key** next to it in the list.

## Access scope

- **Read-only** can only fetch directory data. Use this for embeds
- **Full** can also manage project data. Don't put a Full key in a public web page

## Allowed origins

Allowed origins limit which websites can use a key. Enter one per line, or separate them with commas:

```
https://mywebsite.org
https://www.mywebsite.org
```

If you leave it blank, the key works from any website. For live sites, set allowed origins so others can't reuse your key.

## Key format

FieldFlow API keys start with `ff_live_`. The list shows the start of each key, its scope, when it was created, and its allowed origins.

## Revoking keys

- Click **Revoke** next to a key to turn it off
- Click **Revoke all keys** to turn off every key in the organization

Revoking is immediate and permanent. Any embed using that key stops loading data until you create a new key and update the embed code.

:::caution
Because keys are shared across your organization, revoking a key can break embeds for other projects that use it.
:::

### Legacy keys

Some older keys can't be revealed. You'll see "This key is legacy and cannot be revealed." Revoke it and create a new one, then update your embed code.

## Best practices

- Create one key per website
- Use **Read-only** keys in embeds
- Set allowed origins on keys used by live sites
- Revoke keys you no longer use
