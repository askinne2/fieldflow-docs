The Publish tab writes the embed snippet for you. This page explains the settings in that snippet and a few extra ones for custom setups.

## Detail URL template

By default, clicking a record opens its details inside the embed. To send visitors to pages on your own site instead, set a detail URL template.

**From the dashboard:** On the **Publish** tab, open **Detail page URL (optional)**, enter a URL in **Custom detail URL template (for embed)**, and click **Save template**. This option appears when detail pages are on. The saved template is used by embeds of this project.

**In the snippet:** Add `detailUrlTemplate`. This overrides the saved template for that embed.

```js
window.FieldFlow.q.push({
  projectId: "...",
  apiKey: "...",
  container: "#fieldflow-directory",
  apiBaseUrl: "https://getfieldflow.io",
  detailUrlTemplate: "https://mysite.com/resources/{{externalId}}"
});
```

`{{externalId}}` is replaced with the record's ID. The page opens in a new browser tab.

## Open a specific record on load

Use `openRecordId` to load a directory embed with one record's details already open:

```js
window.FieldFlow.q.push({
  projectId: "...",
  apiKey: "...",
  container: "#fieldflow-directory",
  apiBaseUrl: "https://getfieldflow.io",
  openRecordId: "record-id-here"
});
```

This is useful when a page on your site should show one specific resource.

## Pre-filtering

To load the directory with some categories already selected, use **Start with filters** on the Publish tab. It adds a `preFilter` setting to the snippet:

```js
options: {
  preFilter: { taxonomyId: "taxonomy-id", slugs: ["housing", "food"] }
}
```

Let the Publish tab write this for you, so the IDs are correct.

## Quiz redirect

In **Quiz only** mode, the snippet includes an `onComplete` function. It runs when the visitor finishes the quiz and sends them to your redirect path with their answers added to the URL:

```js
onComplete: function(filters, queryString) {
  window.location = "/resources" + (queryString ? "?" + queryString : "");
}
```

You can also build the URL with `FieldFlow.buildFilterUrl("/resources", filters)`.

## Theme

Add `theme: "light"` or `theme: "dark"` to force a theme. Leave it out to follow the visitor's device. The Publish tab adds this for you when you pick Light or Dark.

## Embed modes

| Mode | Value | Description |
|---|---|---|
| Directory only | `"directory"` | Directory with search and filters (default) |
| Quiz only | `"quiz"` | Quiz, then redirect to your page. Needs `onComplete` |
| Quiz + directory | `"quiz+directory"` | Quiz first, then results in the same embed |

## All configuration options

| Option | Type | Default | Description |
|---|---|---|---|
| `projectId` | string | required | Your project ID |
| `apiKey` | string | required | API key from the Publish tab |
| `container` | string | required | CSS selector for the element to render into |
| `apiBaseUrl` | string | — | `https://getfieldflow.io`. Keep the value from your snippet |
| `mode` | string | `"directory"` | `"directory"`, `"quiz"`, or `"quiz+directory"` |
| `theme` | string | follows device | `"light"`, `"dark"`, or `"system"` |
| `detailUrlTemplate` | string | — | Your own URL for detail pages |
| `openRecordId` | string | — | Open this record's details on load (directory mode) |
| `onComplete` | function | — | Quiz only: called when the quiz finishes |
| `options.preFilter` | object | — | Categories to pre-select |
