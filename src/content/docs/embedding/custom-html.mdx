---
title: Custom HTML
description: Embed a FieldFlow directory on any HTML page.
---

FieldFlow works on any website that lets you add HTML. If your platform isn't WordPress, Webflow, or Squarespace, you can still embed a directory.

## Basic setup

Copy your snippet from the project's **Publish** tab (see [Embed Code](/publishing/embed-code/)) and paste it where you want the directory to appear. It looks like this:

```html
<div id="fieldflow-directory"></div>
<script>
  window.FieldFlow = window.FieldFlow || { q: [] };
  window.FieldFlow.q.push({
    projectId: "YOUR_PROJECT_ID",
    apiKey: "YOUR_API_KEY",
    container: "#fieldflow-directory",
    apiBaseUrl: "https://getfieldflow.io",
    options: { showSearch: true, showFilters: true, itemsPerPage: 20 }
  });
</script>
<script src="https://getfieldflow.io/embed.js" async></script>
```

Replace `YOUR_API_KEY` with a key from the **Publish** tab.

## Placement

- Paste the whole snippet in your page's `<body>`, where the directory should appear
- Keep the parts in the same order: the `<div>`, then the setup script, then the `embed.js` script
- Keep the container `id` (`fieldflow-directory`, or `fieldflow-quiz` for a quiz-only embed) as it is in the snippet
- Give the container room. FieldFlow needs at least 300px of height

## Styling the container

You can style the container element:

```html
<div id="fieldflow-directory" style="max-width: 1200px; margin: 0 auto; min-height: 500px;"></div>
```

FieldFlow's styles are scoped to the embed to avoid clashing with your page's CSS.

## Placing the embed

We recommend one FieldFlow embed per page. Keep the container `id` from your snippet.

## Platforms this works with

This works on any platform that lets you add custom HTML, for example:
- Static HTML sites
- Ghost
- HubSpot
- Wix (with an HTML embed element)
- Any CMS with an HTML or code block
