When you map a column as a **Display field**, you pick a **Field Type**. The type tells FieldFlow how to format the value.

## Available field types

### Text
The default. Shows the value as plain text.

**Use for:** Names, short descriptions, addresses, any short text.

### Long Text
For longer text, such as paragraphs.

**Use for:** Descriptions, bios, notes.

### Email
Shows a clickable email link.

**Example data:** `info@example.org`

### URL
Shows a clickable link.

**Example data:** `https://example.org/apply`

### Phone
Shows a clickable phone link, so visitors on a phone can tap to call.

**Example data:** `(864) 555-0123`

### Number
For numeric values.

**Use for:** Counts, capacities, ages.

### Date
For dates.

**Example data:** `2026-03-15`

### Yes/No
For true/false values.

**Use for:** Columns like "Accepting new clients" or "Wheelchair accessible".

### Coordinates (map)
Holds a location so the record can appear on the map and in a map card on its detail page.

**Example data:** `34.8526, -82.3940` (latitude, then longitude, in one column)

FieldFlow also recognizes separate **Latitude** and **Longitude** columns. To show the map, turn on map view. See [Map View](/display/map-view/).

## Categories are taxonomies, not a field type

To make a column filterable (for example, "Service Type" or "County"), set its **Purpose** to **Taxonomy** instead of picking a field type. See [Taxonomies](/filters-and-search/taxonomies/).

## Automatic formatting by name

FieldFlow also looks at a field's name and label. Fields named like these get special treatment even as plain Text:

| Field name or label contains | Shown as |
|---|---|
| "website" | A website link |
| "phone" or "tel" | A phone link |
| "email" or "mail" | An email link |
| "address" | An address, grouped with contact info on detail pages |
| "hours" or "schedule" | An hours block with a clock icon on detail pages |

## Choosing the right type

| Your data looks like... | Use this |
|---|---|
| Names, short text, addresses | Text |
| Paragraphs | Long Text |
| `https://...` links | URL |
| Phone numbers | Phone |
| Email addresses | Email |
| Dates | Date |
| Numbers | Number |
| Yes / No values | Yes/No |
| Latitude and longitude | Coordinates (map) |
| Categories or tags | Taxonomy purpose (not a field type) |
